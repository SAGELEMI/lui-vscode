# LUI Studio 0.5

LUI 是面向游戏 UI 的 UTF-8、XAML 风格声明式语言。可见布局写在小写 `.lui`，数据和交互写在同名 `.lui.lua`；VS Code 设计器只解释 LUI 和预览状态，绝不执行游戏代码。

## 中文目录语法与 Lua 边界

组件目录就是命名空间。根节点以 `目录:别名="目录路径"` 导入组件目录；标签和属性采用中文，Lua 边界仍保持 ASCII：

```xml
<页面 目录:积木="Presentation/Components" 名称="Tower" 副名称="塔内">
  <积木:页眉 名称="TowerHeader" 标题="{绑定 title}" />
  <进度条 名称="EnemyHealth" 引用="EnemyHp"
          值="{绑定 enemyHp}" 预览.值="72" 最大值="{绑定 enemyMaxHp}" />
</页面>
```

- `目录:别名` 是唯一的新目录导入语法。`别名` 可以是 UTF-8，且在当前文件内唯一。
- 页面没有设备分辨率；设备预设只改变预览视口。每个页面的安全区必须恰好托管一个底层 `视图框` 或 `网格`：`视图框`以正数 px 宽高建立内部设计坐标并等比缩放，`网格`保持固定逻辑像素、由外层视口滚动而不缩放。`画布`保留绝对定位能力。
- `名称`、`副名称`、`引用`、`宽度`、`高度`、`外边距`、`内边距`、`行定义`、`列定义`、`网格.行`、`画布.左`、`文本`、`标题`、`点击`、`变更`、`条件`、`集合`等都是中文源属性。
- `名称` / `副名称` 是纯设计身份，分别唯一且互不冲突。`引用`、`{绑定 ...}` 路径、`{动作 ...}` 键和 `.lui.lua` 访问名必须是 ASCII。
- `预览.属性` 是设计器专用的同属性覆盖值。例如 `预览.文本` 优先于 `<预览><设值>` 和内置样例；游戏运行时忽略所有 `预览.*`。
- `scripts/LUI/lui.project.json` v3 的 `componentDirectories` 以实际目录路径登记中文公开组件名。未导入目录、目录越界、未登记组件、裸全局组件调用和循环组件依赖都会报出明确错误。

旧英文标签、属性、`xmlns:别名` 和旧登记仍可读取，但会显示中文迁移诊断；新建和格式化后的项目应使用本页的中文规范。

## 单标签元素检查器

双击 `.lui` 只打开一个 LUI Studio 标签。标签内部上方是当前文件的结构树、真实预览和中文属性；下方是同一文件的可编辑 CodeMirror 源码，默认约 60% / 40%，中间分隔条可拖动。

- 左侧只列出当前 `.lui` 自己的节点。`<积木:页眉>` 这类引用是一个节点，不会展开组件内部。
- 画布会真实展开已登记组件；点到组件内部时，选择回落到页面中的组件引用节点，源码不会切换文件。
- 树、画布、属性和源码光标会像浏览器 Elements 面板一样相互定位；左侧结构树可拖动宽度并收起。
- 属性面板的“标签类型”只提供内置中文标签和当前文件已导入目录的组件。属性按当前标签可用项显示，Lua `引用`不会在面板中暴露；未知扩展属性保留在“其他属性”。
- 布局分类提供宽高、最小/最大尺寸、外边距、内边距，以及当前父级的网格/画布定位；“布局结果”显示预览中的父坐标、实际坐标、尺寸、内容区和盒模型数据。选中根节点还会列出当前文件全部节点的布局明细。
- 某属性写入 `{绑定 path}` 后，属性面板会显示“预览值”并回写 `预览.属性`。

画布绘制真实文本、按钮、卡片、进度条、滚动区和组件层级，绝不把 `名称` 或 `副名称` 当作游戏文案。编辑器提供 XML 着色、两空格缩进、中文目录/组件/属性补全、枚举中文下拉与值补全、`{绑定}` / `{动作}` 片段、诊断下划线以及撤销重做。所有写回都携带文档版本；版本冲突时以宿主 `TextDocument` 为准回填。

`.lui` 语言贡献自己的深浅色默认文件图标；它不添加右侧格式标记，也不改变用户的 Material Icon Theme。

## 本地开发

```powershell
npm install
npm run check
npm run package:vsix
```

安装 `dist/lui-vscode-0.6.0.vsix` 后重载 VS Code。首次部署运行时时会提示确认；更新只在哈希变化时保留一份 `.backup-last` 完整运行时快照，并会将 `lui.project.json` 的运行时版本、布局契约和清单哈希同步到当前部署，绝不覆盖用户设计文件或 `.meta`。本仓库不含任何具体游戏的领域数据、资源或玩法逻辑。

## 视图框、网格与画布

`视图框`的`宽度`、`高度`是内容设计坐标，不是手机尺寸。它按 `min(可用宽/设计宽, 可用高/设计高)` 缩放并居中；Studio 与 Lua Runtime 共用这个规则和同名节点布局探针。`网格`不缩放，适用于固定逻辑像素布局；根网格在空间不足时由外层滚动承载。

`网格`的 `行定义`/`列定义`用逗号分隔轨道：像素数、百分比、`自动`、`填充`或权重形式如`2填充`。`网格.行`、`网格.列`从 `0` 起，`网格.跨行`、`网格.跨列`控制跨度。`画布`使用左上原点，子项可写 `画布.左`、`画布.上`、`画布.右`、`画布.下`；同一轴只能选择一侧定位。

`外边距`与`内边距`遵循 XAML Thickness：一个数值代表四边一致；四个数值按“左,上,右,下”书写。属性栏和格式化会按规范化属性名折叠重复项（例如`内边距`和旧 `Padding`），保留最后一个值并写回中文属性名。
