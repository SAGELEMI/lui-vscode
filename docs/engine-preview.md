# 2.8.0 项目级运行预览

[返回文档入口](README.md)。适用版本：2.8.0。

## 入口与智能部署

单文件 LUI Studio 固定显示“结构示意”。点击顶部 **运行**，或执行 **LUI: 运行项目预览**，会定位 Maker 项目的 `.project/project.json`，校验 LUI Runtime 版本、布局契约、清单及受管文件哈希。运行时缺失、过期或文件不一致时自动部署扩展内置版本；项目配置、主题、字体和组件登记继续保留，被替换的受管文件保留为一份 `.backup-last`。项目运行时版本高于 Studio 时拒绝降级并提示升级扩展。

校验通过后，扩展启动只监听 `127.0.0.1` 的随机端口和随机会话路径，在独立浏览器顶层页面执行项目入口。服务发送 COOP/COEP 响应头，因此不再经过 VS Code Webview 无法跨源隔离的路径。再次点击 **运行** 会显示既有预览，不重启项目；源码改变后执行 **LUI: 刷新项目预览** 或点击浏览器的 **刷新项目**。

## 设备尺寸和交互

浏览器顶部提供 358×425、377×496、360×800、390×844、640×1024 和 768×1024 逻辑像素。初始值读取 `lui.preview.defaultDevice`，切换尺寸只重建引擎画布，预览服务和会话存储继续保留。项目仍可根据 `graphics:GetDPR()` 和逻辑视口执行自己的适配。

普通点击执行游戏操作。按住 Alt 点击可临时选取 LUI 节点；打开 **选取节点** 后可连续选取。Runtime 回传声明的源码路径、节点路径和实例路径，扩展在 `lui.project.json.sourceRoots` 中验证目标；未打开的文件会自动用 LUI Studio 打开并选中结构树、属性面板与源码范围。组件、虚拟列表模板、重复项和弹窗定位到实际声明文件。源码结构改变后浏览器显示预览已过期，手动刷新后恢复可靠定位。

## 生命周期和性能

预览服务属于工作区，不依赖任何已打开的 `.lui` 标签，直到执行 **LUI: 停止项目预览** 或扩展卸载。脚本和资源只在启动及手动刷新时收集；已验证的引擎缓存按哈希复用。文件变化只发送“源码已有改动”事件，不扫描项目或自动刷新。选取仅在点击时命中遍历，没有逐帧轮询。

项目入口执行前设置活动最高 60 FPS、后台 30 FPS；项目显式设置可覆盖此默认值。LUI Runtime 的增量刷新、虚拟列表和共享测量预算继续按 [绑定与列表](bindings.md) 执行。关闭预览会结束 SSE、HTTP 连接和引擎帧。

浏览器存储使用随机预览会话来源，不读取或覆盖正式玩家存档；同一服务内手动刷新继续使用该来源，因此可保留当前预览进度。停止后再次启动会创建新的随机会话。

## 内联预览内容

产品级 `.lui.preview.json` 已移除。单文件结构示意只读取绑定中的 `预览内容`；标量可直接填写，数组和对象使用 XML 转义后的 JSON。测试需要多状态时由测试工具直接注入数据，不把测试场景文件放回产品目录。

## 验收边界

项目预览与 Maker 游戏使用同一入口、Runtime、声明、业务 Lua、字体和资源；视口尺寸可在浏览器明确选择。最终手机性能仍应以目标设备记录为准。源码仓库中的 `scripts/test-project-run-preview.mjs <游戏根> --serve` 可启动同一宿主，验证完整项目启动、尺寸切换、手动刷新和节点回传。
