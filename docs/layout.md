# 布局

[返回文档入口](README.md)。适用版本：2.5.0。

## 页面与控件

页面宽高是设计坐标，按可用空间等比缩放并居中。设备预设只属于页面预览。`<页面>` 不再在 Runtime 中隐式包裹安全区；只有源码中的显式 `<安全区>` 会改变可用矩形。控件按父级约束及内容测量；独立预览使用自身宽高、绑定的预览内容或内容尺寸，不获取设备安全区。

2.5.0 的 Studio 与 Runtime 由同一组页面框架测试向量约束：视口、设计尺寸、四边距、居中和 contain 缩放必须得到相同结果。布局探针同时输出视口、可用矩形、页面缩放、文字行盒和最终画刷，用于逐节点对照。

宽度、高度支持数值、百分比或自动测量，可以声明最小/最大尺寸。外边距、内边距单值表示四边一致，四值顺序为 **左、上、右、下**，不是 CSS 的顺时针顺序。

## 对齐与排列

LUI 当前轴向与标准 WPF 的同名属性不同：

| 属性 | 控制轴 | 可用值 |
| --- | --- | --- |
| 水平对齐 | Y，上下 | 上、居中、下、拉伸 |
| 垂直对齐 | X，左右 | 左、居中、右、拉伸 |

属性控制自身在父级槽位内的位置，不是文本对齐。父级改变横纵排列不会交换两轴；显式尺寸仍生效，自动尺寸且拉伸才占满相应槽位。

容器及成对视觉节点使用子项排列（自由、水平、垂直），配合水平间隔、垂直间隔、填充、允许换行和固定子项尺寸。精确轨道用网格，绝对定位用画布，不把旧横排/面板当作新语法。

`子项排列`缺省为“自由”，直接子项共享同一内容框并按各自两轴对齐定位。多个子项处于同一锚点且没有层级或变换时会发生叠放，Studio 会给出警告；需要标题和副文上下排列时应在它们的直接父级声明 `子项排列="垂直"`。

2.4.6：自由布局的唯一列占满内容框，按钮居中样式不再缩窄百分比基准。横纵流中的百分比相对父内容框只计算一次。导入控件完整保留其根的宽高、内外边距和对齐；未声明的尺寸随父槽位拉伸，控件独立预览用的尺寸样例不会在导入时固定实际高度。

## 布局容器

| 容器 | 关键属性 |
| --- | --- |
| 网格 | 行定义、列定义：逗号分隔像素数、百分比、自动、填充、2填充；子项用网格.行/列及跨行/跨列 |
| 画布 | 左上原点；子项用画布.左/上/右/下，每轴只能指定一侧 |
| 堆叠面板、换行面板 | 方向、间距；水平方向支持流向="从右到左" |
| 停靠面板 | 子项按源码顺序停靠左/上/右/下；默认左，最后子项填充默认是 |
| 均分网格 | 行数、列数对应均分单元；用控件参考核对属性名 |
| 边框、内容控件、视图框 | 内容组织与尺寸约束；不要推定支持全部 WPF 属性 |

**网格索引从 0 开始，Lua 数组从 1 开始。**

```xml
<控件 名称="GridSample" 宽度="320" 高度="180">
  <网格 行定义="自动,填充" 列定义="填充,自动" 行间距="8">
    <文本 文本="标题" 网格.行="0" 网格.列="0" />
    <按钮 文本="关闭" 网格.行="0" 网格.列="1" />
    <文本 文本="内容" 网格.行="1" 网格.跨列="2" />
  </网格>
</控件>
```

## 滚动、可见性与变换

滚动查看器（兼容别名滚动区）支持任意子内容。横、纵滚动条可见性：自动仅溢出显示，显示为常驻，隐藏保留滚动但隐藏轨道，禁用锁定该方向。未声明时保持旧默认：横向禁用、纵向隐藏。列表要有明确可用高度才能产生溢出。

Runtime 与 Studio 都将可见滚动条作为 8 个逻辑像素的独立视口区域，缺省滑块为 `#8A5CF6`；内容测量、百分比宽度、裁剪和命中使用扣除滚动条后的内容框。常显滚动条始终占位，自动模式仅在对应方向溢出时占位。

可见性区分显示、隐藏、折叠；折叠不占布局空间。裁剪超出控制内容裁剪。

渲染变换接受如 `平移(8,0);缩放(1.1);旋转(8)`，`渲染变换原点="0.5,0.5"`是相对原点。布局变换参与期望尺寸，平移会被诊断并忽略。Studio 能解释的变换不代表 Lua 对每种组合实现了同等效果；当前 Lua 主要映射缩放、旋转和位移，倾斜及复杂组合应在目标运行时验证。

## 按钮文字位置（2.4.7）

`文字左右对齐` 可选左／居中／右；`文字上下对齐` 可选上／居中／下，两项默认居中。仅作用于按钮的文本，与控件自身的水平对齐（Y）、垂直对齐（X）及子项排列独立。文字按扣除边框和内边距后的内容框定位，单行保持声明字号，长文字裁剪在内容框内。复合按钮中的文本控件仍独立布局。

```xml
<按钮 文本="右下角" 宽度="200" 高度="80" 内边距="10,7,20,11" 边框宽度="2" 文字左右对齐="右" 文字上下对齐="下" />
```
