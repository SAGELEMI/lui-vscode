## 外观编辑器（2.5.0）

颜色属性使用颜色选择器和独立 Alpha 滑块；画刷属性可在纯色与线性渐变间切换，并编辑角度、两端颜色和色标位置。编辑结果仍通过 TextDocument 写回源码，因此撤销、重做、冲突检测与普通属性一致。进度条的轨道和进度画刷也使用这套编辑器，不再出现专用的写死渐变。

Studio 从项目 `scripts/LUI/lui.project.json` 读取字体资源，通过 Webview URI 注册 `@font-face`。字体缺失或哈希不匹配会显示明确诊断；预览不会退回系统微软雅黑后继续假装一致。

2.5.2 在项目字体 `document.fonts.ready` 完成前把预览标为未就绪，截图夹具必须等待该状态；全部 LUI 节点使用 `font-synthesis:none`。文本框由真实只读 HTML input 仿真其值、占位文本、颜色和 40px 默认高度，不再显示为空容器。

双击 .lui 进入单个 LUI Studio 标签：上部为结构树、画板和属性，下部为当前文件源码。树只列本文件节点；画板展开已登记组件。点击组件内部可选中实际命中的节点，底部源码仍保持当前文件；重复组件用实例路径区分。

| 命令 | 用途 |
| --- | --- |
| LUI: 打开设计预览 | 打开当前 LUI 文件的 Studio |
| LUI: 部署 UrhoX/Lua 运行时 | 部署运行时、资料及 AI skills |
| LUI: 检查运行时部署 | 检查清单版本、布局契约和哈希 |
| LUI: 生成动作桩 | 为声明的动作提供后端代码辅助，仍需填写业务实现 |
| LUI: 新建页面或组件（MVVM） | 创建配对文件、元数据和注册项 |

新建或重建 Webview 从 100% 开始，普通刷新保留用户倍率；点击适应才计算适应视口比例。画板可滚动、中键/空格拖拽平移，Ctrl+滚轮缩放；倍率范围为 5%–6400%。只有中央画板缩放，结构树、属性及源码不受影响。

页面显示设备预设；控件独立预览不提供设备宿主或额外可用尺寸输入。侧栏可收起，源码与设计区可调整比例。选中/悬停框是独立直角装饰，不改变控件圆角。

属性面板按标签和父级提供合法字段，Lua 引用不在属性栏显示，可在源码填写。布局结果是当前节点的中文盒模型示意。名称和副名称不会被当作游戏显示文本。

源码编辑即时排队同步到 VS Code TextDocument，预览另行防抖；保存遵循 VS Code 设置。Ctrl+S 等待队列提交再保存，不强制自动保存，也不在普通保存时格式化。磁盘保留原有 CRLF/LF，内部偏移使用统一 LF。

输入停顿、移动光标、换行、粘贴、补全与属性修改形成可撤销边界。真实外部重叠修改保留草稿并提示，不以强制覆盖解决。安装升级前先保存或复制旧 Webview 中未落盘的草稿，再按需要重载编辑器。

预览只执行安全解析和布局，不执行同名 Lua、动作或游戏逻辑。真实交互须在游戏宿主验证。

## 按钮文字与条件预览（2.4.7）

选择按钮后，在属性面板设置文字左右对齐和文字上下对齐，复位均为居中；编辑立即写回对应 .lui 属性。位置只改变标题层，不移动整个按钮或重排内部控件。

事件决定可见性的组件可在可见性绑定填写 `预览内容='显示'`，以便独立编辑时看到按钮。导入实例中，实际参数优先（包括 false）；如果 props 路径没有值，尺寸／可见性不会回退使用独立组件样例。其他数据绑定继续使用各自显式预览内容，预览值不会进入游戏运行时。
