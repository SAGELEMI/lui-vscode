# LUI 2.4.1 列表组件契约

> 2.4.2 更新：以下空状态卡片及空标题/空说明接口已废止；空集合现在为空白内容区。模板标签改为重复项。其余稳定 key、原条目事件、实例/页签状态与滚动契约继续有效，详见 workspace-2.4.2-acceptance.md。

本版本保留 UTF-8 显式 Properties、100% 初始倍率、直角高亮和既定轴向。项目组件实现属于游戏 Presentation，不放入通用 Studio。

## 两层组件

- `SelectionList`／列表面板：标题、计数、滚动内容、双行条目和不可点击空状态。公开键：`标题、计数、项目、选中键、选择、空标题、空说明、状态`。
- `TabView`／页签列表：36px 等宽页签，间隔 6px，下方仅引用一个列表面板。在上述键之外公开 `页签、当前页签、切换`。两者都不提供内容插槽，最终尺寸由调用方布局决定。
- 项目需提供非空且唯一的字符串 `key`、`label`、可选 `description`、`disabled`；其他业务字段保留。事件返回原条目，不以名称查找。页签使用稳定 `id` 和 `label`，切换返回原页签。
- 页面提供标题、计数和空文案；组件没有背包容量或天赋上限规则。空集合是真正空表，不再伪造 empty 项。

## 数据与滚动状态

Presentation 的 `GetListState / ReconcileListState / SelectListItem / SwitchListTab` 按实例键和页签 ID 管理 `selectedKey、selectedRow、scrollY`。页签切回恢复详情，数据删除后核对 key 并清除失效选择。状态仅存于会话；进入新整备/新塔及重置流程清理对应状态，不写存档。

`Components/ListModel.lua` 只整理行数据、转发动作和桥接滚动：onScroll 持续保存，首次有效布局后通过 ScrollView.SetScroll 恢复并钳制，不在销毁时临时读取。界面模板、颜色和空状态卡片在 `.lui`。

滚动默认横向禁用、纵向显示。适配器 `Scrollbars.lua` 补齐按轴绘制与空内容常显指示条，沿用 UI 库的滚轮、触控和滚动条交互，不改引擎参考副本。

## 设计与诊断

绑定内 `预览内容` 是静态设计数据；循环允许 JSON 数组预览（XML 引号需写 `&quot;`），只 JSON.parse、不执行 Lua。真实运行值不消费预览数据。新增 `边框宽度、边框颜色、滚动条颜色` 与滚动可见性使用统一词汇。

布局结果只显示当前节点：位置、外边距、控件边界、内边距、内容区域。各标题独立网格行；数值不与嵌套层争用绝对定位空间。该区域禁止鼠标选择，源码和属性输入不受影响。

运行时同时修复根“控件”被 UI.Widget 同名词覆盖、字符串键绑定的引号状态和中文滚动可见性解析；嵌套生产解析与事件测试见 `scripts/test-lists-lua.py`。
