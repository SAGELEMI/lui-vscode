# 迁移与兼容

[返回文档入口](README.md)。适用版本：2.5.0。

## 迁移到 2.5.0

旧的背景、颜色、边框颜色、边框宽度和圆角无需改写。部署 2.5.0 Runtime 后，检查项目字体声明与 SHA-256，再删除宿主为 `<页面>` 人工添加的隐式安全区；需要安全区的页面应在 LUI 源码中显式声明。此前依赖默认进度渐变的页面保持原外观，新设计可改用轨道画刷、进度画刷和进度方向。

若旧宿主只注册 Regular 字体，必须补充真实 Bold 文件；不要把 Regular 以 bold 名称重复注册。Studio 和游戏都应使用配置中的同一资源路径。升级到 2.5.2 后重新部署 Runtime，使所有视觉标签获得向内边框、单次文字栅格和正确的原生叶控件首帧尺寸；不要通过手工调亮边框或重复绘字补偿差异。

升级前保存未落盘草稿，保留原配置和设计文件。部署运行时会保留作者登记，更新版本、契约与清单哈希，并维护运行时备份。资料升级保护规则见 [运行时接入](runtime.md)。

| 遗留写法或假设 | 当前写法 |
| --- | --- |
| 英文标签、属性、xmlns 目录导入 | 中文标签和属性，根使用目录:别名 |
| 循环 | 重复项；原项目别名和集合绑定保持 |
| 预览.属性、预览/设值节点 | 绑定内预览内容；集合使用纯 JSON |
| 通过 Lua 返回 Build 的树 | 同名类 New → InitializeComponent → RenderMarkup |
| 从内部用法推导组件属性 | 同名 Lua 的 Properties 字面量声明 |
| 中文属性隐式转英文 | 调用处、props 索引与 Lua 字符串键精确同名 |
| 按标准 WPF 理解对齐轴 | 水平对齐控制上下，垂直对齐控制左右 |
| 所有根使用设备预设 | 只有页面使用设备，控件按自身约束测量 |
| 首次打开自动适应 | 新建 Webview 从 100% 开始，用户点击适应 |
| 保存时自动格式化/清理边距 | 普通保存保留文本；需要规范化时显式格式化 |

旧英文语法与循环可读取并产生迁移诊断，新文档不再生成。旧版对齐轴迁移只改确定的静态值：水平左/右转为上/下，垂直上/下转为左/右；居中/拉伸不改。绑定值必须核对数据源，不能搜索替换整份 Lua 或文案。

先选一对页面及其组件做迁移，验证真实数据和交互，再扩展范围。不要因为某个示例使用特定布局、颜色或业务列表就批量修改所有设计。

2.4.3 保持 2.4.2 语言和公开 Runtime 调用兼容，新增的是资料交付与清单对照检查。历史验收文件保留在 LUI 源码仓库，不是新项目必须照抄的规则。

2.4.4 新增可选的按钮 `悬停背景`、`按下背景`。旧设计无需迁移；仅声明 `背景` 的按钮会在全部交互状态保持该颜色。

2.4.6 需要核对此前为缩窄预览作出的尺寸补偿：导入控件现在保留根声明，缺省宽度拉伸；根的静态高度仍然有效。不要统一把自由排列改为垂直：并列文字改为明确横纵排列，互斥视图、伤害数字等有意重叠层保留自由排列并显式登记层级。升级使用正式适配器部署，安装扩展后重载 VS Code 窗口以加载新版 Studio。

## 2.4.7 按钮标题迁移

新增属性为兼容扩展，缺省仍居中。对使用文本的按钮补全显式居中，不改已有对齐值，也不改复合按钮的子项布局。使用 LUI 源仓库的 `node scripts/migrate-button-captions.mjs <设计目录> --write`；不带 --write 只检查，有待迁移文件时退出码为 1。支持多个目录；保留注释、换行与其他属性，重复执行 changed 为 0。

可选事件控制的按钮须在 .lui 的可见性绑定提供独立预览值，并验证实际调用页的有／无参数状态。随后构建并部署正式运行时、资料及新扩展，不能只复制设计器脚本。无需改动玩法存档。
