# LUI 2.4.4 交付记录

2.4.4 保持 Studio 正常预览为基准，修正 UrhoX/Lua Runtime 的复合按钮转换一致性。

- 新增按钮 `悬停背景`、`按下背景`；显式 `背景` 在未声明交互色时不再被底层主题自动替换。
- 复合按钮文字测量当时采用 1.2 行高；“与 Studio 一致”的结论后来确认错误，2.4.5已统一为1.45。内容框继续排除边框与内边距。
- Studio 保留 100% 初始倍率、矩形选择框及折叠节点不占位规则。
- 打包产物为 `dist/lui-vscode-2.4.4.vsix`。

Runtime 修改只发生在正式适配器，部署脚本负责生成游戏侧备份并同步清单哈希。
