# LUI 0.4 中文语言约定

LUI 使用安全 XML 子集：元素、属性、嵌套、注释、条件、循环、预览和受限绑定/动作。不支持 DTD、外部实体、内嵌脚本或任意表达式。设计文件后缀固定为小写 `.lui`；同名 `.lui.lua` 是数据、动作和局部刷新的后端。

## 源语法

```xml
<页面 目录:积木="Presentation/Components" 名称="Tower" 副名称="塔内">
  <文本 名称="EnemyText" 引用="EnemyText"
        文本="{绑定 enemyText}" 预览.文本="塔层守卫 · Lv.1" />
  <积木:页眉 名称="TowerHeader" 标题="{绑定 title}" />
  <条件 条件="{绑定 battleVisible}">
    <进度条 名称="EnemyHp" 引用="EnemyHp" 值="{绑定 enemyHp}" 最大值="{绑定 enemyMaxHp}" />
  </条件>
  <预览 名称="Battle" 副名称="战斗预览"><设值 路径="title" 值="第 12 层" /></预览>
</页面>
```

| 类别 | 示例 | 约束 |
| --- | --- | --- |
| 目录导入 | `目录:积木="Presentation/Components"` | 别名在文件内唯一；目录必须在项目内 |
| 设计身份 | `名称="Tower" 副名称="塔内"` | 各自唯一且不能互相冲突 |
| Lua 控件引用 | `引用="EnemyHp"` | 仅 ASCII；写入 `context.refs.EnemyHp` |
| 绑定 | `文本="{绑定 profile.coins}"` | 仅 ASCII 点分路径 |
| 动作 | `点击="{动作 OpenTower}"` | 仅 ASCII 动作键 |
| 条件 | `<条件 条件="{绑定 hasRun}">` | 条件在 Lua 中预先计算 |
| 循环 | `<循环 项目="entry" 集合="{绑定 entries}">` | 使用数组顺序 |
| 内联预览 | `预览.文本="第 12 层"` | 仅设计器读取，优先级最高 |
| 预览状态 | `<预览><设值 路径="title" 值="第 12 层" /></预览>` | 仅设计器读取，提供页面状态值 |

内置标签为 `页面`、`组件`、`面板`、`横排`、`文本`、`按钮`、`卡片`、`滚动区`、`进度条`、`开关`、`滑块`、`安全区`、`弹窗`、`分区`、`提示`、`屏幕`、`固定屏幕`、`条件`、`循环`、`插槽`、`预览`、`设值`。公开组件也使用中文名称，例如 `<积木:页眉>` 与 `<积木:装备槽>`。

运行时将中文标签和属性归一化为内部语义，所以 `.lui.lua` 不需要跟随文案或标签改名。`预览.*` 被运行时忽略。旧英文 LUI、`xmlns:别名` 及 v1/v2 组件登记仍可读取，但都会给出迁移诊断。

## 单标签设计器

`.lui` 的默认编辑器是单一 LUI Studio 标签：上半区为当前文件元素树、真实预览和中文属性，下半区为当前文件的内嵌 CodeMirror 源码。元素树不会展开已引用组件；画布会展开它们以呈现实际效果。点击组件内部视觉元素会回到当前页面的组件引用节点，绝不切换底部源码文件或创建 VS Code 编辑器组。

属性面板按标签类型提供适用属性，包含布局的外边距、内边距、宽高、锚点、四边定位、间距和弹性布局；“其他属性”用于保留扩展字段。树、画布、属性和源码光标按范围双向定位，左侧树可拖动并可收起。源码和属性通过带版本号的 `WorkspaceEdit` 写回宿主 `TextDocument`；旧版本写入会被宿主内容替换。

`.lui.lua` 应返回 `view`、`actions`、挂载和原位刷新逻辑，不能调用 `UI.Panel`、`C.Row` 或构建布局。
