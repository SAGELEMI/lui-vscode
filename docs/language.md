# LUI 语言规范

[返回文档入口](README.md)。适用版本：2.4.3。

## 文件与语法

使用 UTF-8 和小写扩展名 .lui，同名后端为 .lui.lua。语言是受限 XML 子集，支持元素、属性、嵌套、注释与属性元素；不支持 DTD、外部实体、任意表达式或嵌入 Lua。属性中的 &、<、双引号使用相应 XML 实体。

根只能是页面或控件，必须声明名称。页面必须声明正数设计宽高；控件可自动测量。子节点可不命名。成对视觉标签可放子节点，底层控件内容能力见 [控件参考](controls.md)。

```xml
<页面 名称="Demo" 副名称="示范页面" 宽度="390" 高度="844">
  <容器 子项排列="垂直" 内边距="16">
    <文本 文本="你好，LUI" />
    <按钮 点击="{动作 Confirm}">
      <按钮.文本>确认</按钮.文本>
    </按钮>
  </容器>
</页面>
```

新文件使用中文语法。普通保存不格式化，显式格式化会规范属性名并处理同义重复属性。旧语法见 [迁移](migration.md)。

## 名称与路径

| 写法 | 作用与约束 |
| --- | --- |
| 名称="Demo" | 设计身份，支持中文，文件内唯一且与副名称不冲突 |
| 副名称="示范页面" | 可读设计身份，不会成为游戏文案 |
| 引用="StatusText" | ASCII Lua 访问键，对应 context.refs.StatusText |
| `{动作 Confirm}` | 查找 context.actions.Confirm，动作键为 ASCII |
| `{绑定 view.title}` | 读取当前视图模型，不执行表达式 |
| `{绑定 props['标题']}` | 中文键精确同名，对应 Lua `props["标题"]` |
| 目录:积木="Presentation/Components" | 根节点导入目录，别名支持中文且文件内唯一 |

绑定支持受限点路径和字符串索引，中文键推荐方括号形式。禁止函数调用、计算或条件表达式，改在 Lua 中计算字段。设计身份不是绑定路径。

## 目录组件

```xml
<页面 目录:积木="Presentation/Components" 名称="ComponentDemo" 宽度="390" 高度="844">
  <积木:操作卡 标题="准备完成" 确认="{动作 Confirm}" />
</页面>
```

目录相对游戏 scripts 资源根，必须匹配 lui.project.json 的 componentDirectories。操作卡是登记的公开名称，不要求与文件名相同。裸全局组件名、未登记别名、越界路径及循环依赖不能用于新项目。Registry 负责实例发现，componentDirectories 负责带目录别名的组件调用，二者不能互相替代。详见 [组件](components.md)。

## 条件与重复项

`<条件 条件="{绑定 view.showDetails}">`按预先计算的布尔字段构建内容。`<重复项 项目="row" 集合="{绑定 view.rows}">`按数组顺序展开模板，不增加容器。row 与 item 指向当前项，嵌套模板保留外层别名。

条件和集合在构建阶段求值，数据改变不会自动重建整棵树；刷新见 [绑定与事件](bindings.md)。
